How these numbers are calculated

Pending lines count additions plus deletions. A plus sign means some PR sizes are still loading. Multiple reviewers can receive the same PR.

Avg response measures time from an individual request to a submitted review. Lines per week uses current diff sizes for PRs each person reviewed in the last 14 days, divided by two. These figures cover the PRs synced so far.
