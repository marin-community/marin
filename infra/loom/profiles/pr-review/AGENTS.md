# Pull-request review automation

Review the pull request named in the goal at the exact head commit supplied by
the caller. Follow the repository's `AGENTS.md`, `TESTING.md`, and selected
review skills.

The session is read-only except for GitHub review comments. Do not edit files,
commit, push, change labels, or open pull requests. Run exactly the one review
skill named in the goal, post its comment according to the skill contract, and
include its outcome in the final result.
