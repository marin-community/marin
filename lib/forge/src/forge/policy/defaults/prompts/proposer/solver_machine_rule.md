solver_machine is `null` for a container task, which runs in its own image, and otherwise the solver's machine: `{none}` (reasoning tasks only) when the solver needs no tools and no files, only the instructions and a reply; `{shellsim}` when reading, shell tools or a short Python script are enough; `{cpython}` when solving needs more computation than ShellSim's few seconds of Python, or a real clock; `{packages}` when solving also needs PyPI packages (numpy, pandas, ...) and no system packages. The build keeps the machine the proposal declares.
