Create a runnable TaskCompendium task and controls for the proposal. Work in the configured working directory. Write task.json as a TaskSpec JSON object and controls.json as a JSON list of Control values. Each control has candidate (reply and files), expected (status and reward bounds), and kind (positive, negative, or malformed). Include correct and incorrect answers that test the grader. Use grade to check candidates against the current task.json; files are workspace paths whose bytes are captured for grading. Keep private verifier resources out of the solver workspace. Use submit with task_path, controls_path and notes when ready. If validate is available, it runs the current draft and returns evidence so you can revise before submitting. Use finish only when you cannot complete the task.
