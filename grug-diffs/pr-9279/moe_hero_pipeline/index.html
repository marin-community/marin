tt1# Hero pipeline variant
2 
3`pipeline.py` adapts `moe_pipeline` to the model in [`moe_hero_ep`](../moe_hero_ep/README.md), preserving
4latent/shared experts, SConv, absolute local/global attention positions, and QB
5router updates. Standard 1F1B is the default. Each process initializes only its
6own stage. CPU tests compare sequential-stage hidden states, routing statistics,
7losses, and gradients against the unsplit model.
8 
9The synthetic runner does not restore or save checkpoints. Its AdamW default is
10a bring-up configuration; the validated long-context recipe explicitly selects
11BF16 MuonH and both host offloads. Production continuation and long-run training
12stability remain unvalidated.
13 
14## Validated result
15 
16The full 535,477,106,688-parameter, 48-layer model completed ten finite synthetic
17updates at sequence length 65,536 on 192 H100s in `cw-rno2a`. The recipe uses
18PP24/EP8, one process per eight-GPU worker, batch 384, 48 microbatches, six expert
19transport waves, and FA4 (`gpu_fa4_cute`). No FP8 was needed.

32## Runtime requirements
33 
34The measured runs used JAXPP `46b8443eed01f54688dd24ae451203a504b1cff8` with
35local overlays. A stock installation of that pin is insufficient. Required
36pieces are:
37 
38- Preserve Host/Device memory targets during mesh rebinding
39  ([NVIDIA/jaxpp#13](https://github.com/NVIDIA/jaxpp/issues/13)).
40- Keep activation D2H copies in the forward partition and preserve pinned-host
41  intermediate shardings. This saved 12 GiB/device at eight outstanding
42  microbatches in the 24-layer diagnostic.
43- Include the Dime2 send-buffer lifetime fix from upstream
44  [78458f8](https://github.com/NVIDIA/jaxpp/commit/78458f8b258f0fd467be13b4b8e7056a853e320b).
45- Precompile and warm local tasks with disposable inputs before pipeline
46  transfers; initialize adjacent communication channels before stepping.
47- Park real device state on host during disposable warmup, then restore its
48  original values and shardings.
49 
50The runner retains `--synchronize-devices-after-step`: two unsynchronized full
51m8 trials produced NaNs, while synchronized trials passed. This is a timing
52workaround with an unresolved root cause. Do not remove it from the validated
53recipe based only on successful small tests.
54 
55Use the `pipeline` dependency environment and CUDA toolchain. After applying
56the dependency overlays, reproduce the worker configuration with:

86 
87The small Muon expert-stack sharding correction and its numerical regression

590    """Copy device state to host, then invalidate all original local device buffers.
591 
592    Callers must discard aliases of the original state and restore the returned
593    state before training. Already-host-resident optimizer arrays remain intact.
594    """

597    parked = []
598    original_shardings = []

115def _initialize_pipeline_communicators(mpmd_mesh, placements: tuple[int, ...]) -> None:
116    # Create every neighboring channel before a blocking NCCL group can prevent
117    # a stage from reaching another stage's communicator initialization.
118    edges = sorted({tuple(sorted((a, b))) for a, b in itertools.pairwise(placements) if a != b})
119    for left, right in edges:
120        for source, target in zip(
121            mpmd_mesh.unstack[left].devices.flat, mpmd_mesh.unstack[right].devices.flat, strict=True
122        ):
123            if jax.process_index() not in (source.process_index, target.process_index):
124                continue
125            if env_vars.jaxpp_directional_communicators.value:
126                dime2.get_or_create_comm(dime2.UniqueDevices(source, target))
127                dime2.get_or_create_comm(dime2.UniqueDevices(target, source))
128            else:
129                dime2.get_or_create_comm(dime2.UniqueSortedDevices(source, target))
130    barrier_sync_named("hero_pipeline_communicators_initialized", timeout=_MULTIHOST_TIMEOUT)
131 
132    # NCCL establishes P2P transports on the first send/recv, even after
133    # communicator initialization. Connect both directions in a common edge
134    # order before pipeline scheduling can introduce a blocking setup cycle.
135    for left, right in edges:
136        left_mesh, right_mesh = mpmd_mesh.unstack[left], mpmd_mesh.unstack[right]
137        if any(device.process_index == jax.process_index() for device in left_mesh.devices.flat):
138            local_stage, remote_stage = left, right
139        elif any(device.process_index == jax.process_index() for device in right_mesh.devices.flat):
140            local_stage, remote_stage = right, left
141        else:
142            continue
143        local_sharding = NamedSharding(mpmd_mesh.unstack[local_stage], P())
144        remote_sharding = NamedSharding(mpmd_mesh.unstack[remote_stage], P())
145        payload = jax.make_array_from_callback(
146            (1,), local_sharding, lambda _, stage=local_stage: np.full((1,), stage, dtype=np.float32)
147        )
148        recv_buffer = jax.make_array_from_callback((1,), local_sharding, lambda _: np.zeros((1,), dtype=np.float32))
149        transfer = dime2.start_transfer([payload], [remote_sharding], [recv_buffer], [remote_sharding])
150        (received,) = transfer.done()
151        received.block_until_ready()
152        for shard in received.addressable_shards:
153            actual = np.asarray(shard.data)
154            if not np.all(actual == remote_stage):
155                raise RuntimeError(f"Pipeline channel {remote_stage}->{local_stage} received {actual}")
156    barrier_sync_named("hero_pipeline_channels_connected", timeout=_MULTIHOST_TIMEOUT)

420def _run_grug_local(config: GrugRunConfig) -> None:
421    """Entry point for the grug template training loop."""

423    trainer.initialize()
424    levanter.tracker.log_configuration(config)
425 
426    run_id = trainer.id
427    if run_id is None:
428        raise ValueError("trainer.id was not initialized")
429 
430    optimizer = config.optimizer.build(trainer.num_train_steps)
431    watch_config = trainer.watch
432    backward_flow_config = config.trainer.backward_flow if config.trainer.backward_flow.is_enabled else None

440        backward_flow_config=backward_flow_config,
441    )

444    if config.trainer.data_seed is not None:
445        data_key = jax.random.PRNGKey(config.trainer.data_seed)
446 
447    # Grug uses raw PartitionSpecs rather than Trainer's logical axis mapping.
448    # Keep the mesh compact so P(("replica_dcn", "data")) spans slices directly.
449    mesh = compact_grug_mesh()
450    checkpointer = trainer.checkpointer.create(run_id)
451    with set_mesh(mesh), TrainingDashboard(config, checkpointer.request_checkpoint, run_id):
452        batch_schedule = trainer.batch_schedule
453 
454        train_dataset = build_train_dataset(
455            config.data,
456            max_seq_len=config.model.max_seq_len,
457            batch_schedule=batch_schedule,
458            key=data_key,
459        )
460        train_loader = build_train_loader(
461            train_dataset,
462            batch_schedule=batch_schedule,
463            mesh=mesh,
464            batch_pspec=config.trainer.train_batch_pspec,
465        )
466 
467        @jax.jit
468        def _init_state(model_rng):
469            return initial_state(
470                config.model,
471                optimizer=optimizer,
472                mp=trainer.mp,
473                key=model_rng,
474                ema_beta=config.trainer.ema_beta,
475            )
476 
477        state = _init_state(model_key)
478 
479        state = restore_grug_state_from_checkpoint(
480            state,
481            checkpoint_search_paths=trainer.checkpoint_search_paths(run_id),
482            load_checkpoint_setting=trainer.load_checkpoint,
483            mesh=mesh,
484            allow_partial=trainer.allow_partial_checkpoint,
485        )
486        if trainer.initialize_from is not None:
487            state = init_weights_only_from_checkpoint(
488                state,
489                trainer.initialize_from,
490                mesh=mesh,
491                allow_partial=trainer.allow_partial_checkpoint,
492            )
493        dump_grug_state_sharding_run_artifact(
494            state,
495            log_dir=trainer.log_dir,
496            run_id=run_id,
497            path_override=config.trainer.sharding_dump_path,
498        )
499 
500        levanter.tracker.log_summary({"parameter_count": parameter_count(state.params)})
501 
502        flops_per_example, flops_summary = _compute_flops(model_config=config.model)
503        levanter.tracker.log_summary(flops_summary)
504 
505        eval_cfg = config.eval
506        evaluator = None
507        if eval_cfg is not None:
508            evaluator = build_tagged_evaluator(
509                data_config=config.data,
510                max_seq_len=config.model.max_seq_len,
511                mesh=mesh,
512                eval_cfg=eval_cfg,
513            )
514 
515        profiler_cfg = trainer.profiler
516        profiler_num_steps = profiler_cfg.resolve_num_profile_steps(num_train_steps=trainer.num_train_steps)
517        profiler_enabled = profiler_cfg.is_enabled and profiler_num_steps > 0
518 
519        log_every = max(1, config.trainer.log_every)
520        iterator = LoadingTimeTrackerIterator(train_loader.iter_from_step(int(state.step)))
521 
522        state_callbacks = StateCallbackRunner[GrugTrainState](
523            step_getter=lambda s: s.step,
524            model_getter=lambda s: s.params,
525            eval_model_getter=lambda s: s.ema_params if s.ema_params is not None else s.params,
526            opt_state_getter=lambda s: s.opt_state,
527        )
528        state_callbacks.add_hook(
529            callbacks.log_performance_stats(config.model.max_seq_len, batch_schedule, flops_per_example),
530            every=log_every,
531        )
532        state_callbacks.add_hook(callbacks.pbar_logger(total=trainer.num_train_steps), every=log_every)
533        state_callbacks.add_hook(callbacks.log_step_info(trainer.num_train_steps), every=log_every)
534        if profiler_enabled:
535            state_callbacks.add_hook(
536                profiler_cfg.build(
537                    str(trainer.log_dir / run_id / "profiler"),
538                    run_id=run_id,
539                    num_steps=profiler_num_steps,
540                ),
541                every=1,
542            )
543        state_callbacks.add_hook(_make_mixture_stage_callback(train_dataset, batch_schedule), every=1)
544        if evaluator is not None and eval_cfg is not None:
545            interval = eval_cfg.steps_per_eval

552                        eval_current=eval_cfg.eval_current,
553                        eval_ema=eval_ema,
554                    ),
555                    every=interval,
556                )
557 
558        last_loss: float | jax.Array = 0.0
559        last_step_duration = 0.0
560        backward_flow_graph: BackwardFlowGraph | None = None
561 
562        # Main optimization loop.
563        try:
564            while int(state.step) < trainer.num_train_steps:
565                with jax.profiler.TraceAnnotation("load_batch"):
566                    batch = next(iterator)
567                step_start = time.perf_counter()
568                current_step = int(state.step)
569                # grad_watch runs only on its configured interval.
570                compute_watch = (
571                    watch_config.is_enabled and watch_config.interval > 0 and current_step % watch_config.interval == 0
572                )
573                compute_backward_flow = (
574                    backward_flow_config is not None
575                    and backward_flow_config.interval > 0
576                    and current_step % backward_flow_config.interval == 0
577                )
578                state, metrics, watch_stats = train_step(
579                    state,
580                    batch,
581                    compute_watch=compute_watch,
582                    compute_backward_flow=compute_backward_flow,
583                )
584                backward_flow_stats = metrics.get(_BACKWARD_FLOW_METRICS_KEY)
585                if backward_flow_stats is not None:
586                    metrics = {key: value for key, value in metrics.items() if key != _BACKWARD_FLOW_METRICS_KEY}
587                step = int(state.step) - 1
588 
589                jax.block_until_ready(metrics["train/loss"])
590                duration = time.perf_counter() - step_start
591                backward_flow_timing_metrics = None
592                if compute_backward_flow:
593                    backward_flow_timing_metrics = {"backward_flow/compute_step_duration": duration}
594 
595                hook_start = time.perf_counter()
596                with jax.profiler.TraceAnnotation("callbacks"):
597                    state_callbacks.run(state, loss=metrics["train/loss"], step_duration=duration)
598                    last_loss = metrics["train/loss"]
599                    last_step_duration = duration
600                    levanter.tracker.log({"throughput/hook_time": time.perf_counter() - hook_start}, step=step)
601                    levanter.tracker.log({"throughput/loading_time": iterator.this_load_time}, step=step)
602 
603                    if watch_stats is not None:
604                        levanter.tracker.log(watch_stats, step=step)
605                    if backward_flow_timing_metrics is not None:
606                        levanter.tracker.log(backward_flow_timing_metrics, step=step)
607                    if backward_flow_stats:
608                        levanter.tracker.log(backward_flow_stats, step=step)
609                        if backward_flow_graph is None:
610                            backward_flow_graph = _build_backward_flow_graph(
611                                params=state.params,
612                                batch=batch,
613                                mp=trainer.mp,
614                                z_loss_weight=config.trainer.z_loss_weight,
615                            )
616                        artifact_start = time.perf_counter()
617                        _write_backward_flow_artifact(
618                            graph=backward_flow_graph,
619                            backward_flow_metrics=backward_flow_stats,
620                            log_dir=trainer.log_dir,
621                            run_id=run_id,
622                            step=step,
623                        )
624                        levanter.tracker.log(
625                            {"backward_flow/artifact_write_duration": time.perf_counter() - artifact_start},
626                            step=step,
627                        )
628 
629                if checkpointer is not None:
630                    checkpointer.on_step(tree=state, step=int(state.step))
631        except BaseException:
632            logger.exception(
633                "Fatal error in grug training loop; skipping final callbacks/checkpoint to preserve root cause"
634            )
635            raise
636        else:
637            # Mirror classic trainer behavior: force callbacks on the last completed step.
638            state_callbacks.run(state, loss=last_loss, step_duration=last_step_duration, force=True)
639            if checkpointer is not None:
640                checkpointer.on_step(tree=state, step=int(state.step), force=True)
641                checkpointer.wait_until_finished()
642 
643    levanter.tracker.current_tracker().finish()
