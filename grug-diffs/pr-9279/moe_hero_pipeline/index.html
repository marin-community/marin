tt1# Hero pipeline variant
2 
3`pipeline.py` adapts `moe_pipeline` to the model in [`moe_hero_ep`](../moe_hero_ep/README.md), preserving
4latent/shared experts, SConv, absolute local/global attention positions, and QB
5router updates. Standard 1F1B is the default. Each process initializes only its
6own stage. CPU tests compare sequential-stage hidden states, routing statistics,
7losses, and gradients against the unsplit model.
8 
9The synthetic runner does not restore or save checkpoints. `--main-hero-recipe`
10uses FP32 parameters, BF16 compute and compute-scaled MuonH; it requires
11`--optimizer muonh` and an explicit `--processes-per-task` count.
12The legacy AdamW default is a bring-up configuration. The historical long-context
13recipe explicitly selects BF16 MuonH and both host offloads. Production
14continuation and long-run training stability remain unvalidated.
15 
16The current optimizer normalizes each layer's routed expert bank together, matching
17the stacked EP model. Set `--expert-normalization per_expert` for a comparison;
18the shared `GrugMoeMuonHConfig.expert_normalization` selects this choice.
19The historical hardware runs used the earlier per-expert behavior; they do not
20validate this normalization correction. The current optimizer and frozen-QB
21options have CPU numerical/state-transition coverage.
22 
23QB bias adapts after each update by default. Set `--qb-bias-mode frozen` to
24retain the current pending bias while continuing to train expert and router weights. This controls the QB bias
25only; it does not freeze the router weights. Frozen QB has CPU state-transition
26coverage but has not been evaluated for SFT or RL training quality.
27 
28## Historical validated result
29 
30The full 535,477,106,688-parameter, 48-layer model completed ten finite synthetic
31updates at sequence length 65,536 on 192 H100s in `cw-rno2a`. The recipe uses
32PP24/EP8, one process per eight-GPU worker, batch 384, 48 microbatches, six expert
33transport waves, and FA4 (`gpu_fa4_cute`). No FP8 was needed.

41collection and inter-step overhead. These are systems measurements from fresh
42initialization with synthetic data, not training-quality results. The complete
43scaling table, negative results, dependency findings, and W&B links are in
44[experiment #9277](https://github.com/marin-community/marin/issues/9277).
45 
46PP24 gives two transformer layers per stage, reducing the parameters and
47optimizer state owned by each worker. EP8 keeps expert communication within
48an eight-GPU worker's NVLink fabric. CP1 was the initial working integration;

50than through a matched comparison with PP8/EP32/CP4. More pipeline stages also
51increase the number of microbatches needed to amortize pipeline fill and drain.

54update; differing batch sizes and attention-helper versions prevent an isolated
55CP comparison. No matched Megatron layout benchmark was performed.

57## Historical runtime requirements
58 
59The measured runs used JAXPP `46b8443eed01f54688dd24ae451203a504b1cff8` with
60local overlays. A stock installation of that pin is insufficient. Required
61pieces are:
62 
63- Preserve Host/Device memory targets during mesh rebinding
64  ([NVIDIA/jaxpp#13](https://github.com/NVIDIA/jaxpp/issues/13)).
65- Keep activation D2H copies in the forward partition and preserve pinned-host
66  intermediate shardings. This saved 12 GiB/device at eight outstanding
67  microbatches in the 24-layer diagnostic.
68- Include the Dime2 send-buffer lifetime fix from upstream
69  [78458f8](https://github.com/NVIDIA/jaxpp/commit/78458f8b258f0fd467be13b4b8e7056a853e320b).
70- Precompile and warm local tasks with disposable inputs before pipeline
71  transfers; initialize adjacent communication channels before stepping.
72- Park real device state on host during disposable warmup, then restore its
73  original values and shardings.
74 
75The runner retains `--synchronize-devices-after-step`: two unsynchronized full
76m8 trials produced NaNs, while synchronized trials passed. This is a timing
77workaround with an unresolved root cause. Do not remove it from the validated
78recipe based only on successful small tests.
79

284    layer_counts: tuple[int, ...] | None = None,

286    """Partition contiguous Hero layers while keeping boundary modules on edge stages."""

288    if layer_counts is None:

290    else:

307                embed_gated_norm=stage.embed_gated_norm if is_first else None,

310                final_norm=stage.final_norm if is_last else None,
311                final_gated_norm=stage.final_gated_norm if is_last else None,

605def park_pipeline_state(state: GrugMoeAutomaticPipelineState) -> ParkedPipelineState:
606    """Free device memory for disposable warmup by parking real state on host.
607 
608    Device buffers are invalidated after their host copies complete. Callers must
609    discard aliases of the original state and restore the returned state before
610    training. Already-host-resident optimizer arrays remain intact.
611    """
612    pp, _ = _jaxpp_modules()
613    originals, tree = jax.tree.flatten(state)
614    parked = []
615    original_shardings = []
616    device_arrays = {}
617    local_device_bytes = 0
618    for value in originals:
619        assert isinstance(value, pp.MpmdArray)
620        original = value._mpmd_sharding
621        original_shardings.append(original)
622        if original.memory_kind == _HOST_MEMORY_KIND:
623            parked.append(value)
624            continue
625        local = value.to_mpmd_local_array
626        assert local is None or isinstance(local, jax.Array), "Each process must own one pipeline stage"
627        host_arrays = []
628        if local is not None:
629            host = _copy_array_to_host(local)
630            host.block_until_ready()
631            host_arrays.append(host)
632            if id(local) not in device_arrays:
633                local_device_bytes += sum(shard.data.nbytes for shard in local.addressable_shards)
634                device_arrays[id(local)] = local
635        parked.append(
636            pp.MpmdArray(
637                host_arrays,
638                dataclasses.replace(original, memory_kind=_HOST_MEMORY_KIND),
639                shape=value.shape,
640                dtype=value.dtype,
641            )
642        )
643    # Finish every copy before deleting anything: aliases can occur across state leaves.
644    for array in device_arrays.values():
645        array.delete()
646    return ParkedPipelineState(jax.tree.unflatten(tree, parked), tuple(original_shardings), local_device_bytes)

128def _initialize_pipeline_communicators(mpmd_mesh, placements: tuple[int, ...]) -> None:

130    # a stage from reaching another stage's communicator initialization.

356            compute_params = mp.cast_to_compute(params)
357            return compute_params.next_token_loss(
358                batch.tokens,
359                batch.loss_weight,
360                mask=batch.attn_mask,
361                reduction="mean",
362                logsumexp_weight=z_loss,
363                loss_implementation=loss_implementation,
364            )
365 
366        backward_flow_stats = None
367        if backward_flow_config is not None and compute_backward_flow:
368            gradient_scale = jnp.sum(jnp.asarray(batch.loss_weight, dtype=jnp.float32))
369            with capture_backward_flow(backward_flow_config, gradient_scale=gradient_scale):
370                with levanter.tracker.defer_tracker_for_jit() as backward_flow_stats:
371                    loss, grads = jax.value_and_grad(loss_fn)(state.params)
372        else:
373            loss, grads = jax.value_and_grad(loss_fn)(state.params)
374        updates, opt_state = optimizer.update(grads, state.opt_state, state.params)
375        params = optax.apply_updates(state.params, updates)
376 
377        if ema_beta is None:
378            ema_params = None
379        else:
380            if state.ema_params is None:
381                raise ValueError("ema_params must be initialized when ema_beta is set.")
382            ema_params = jax.tree_util.tree_map(
383                lambda old, new: ema_beta * old + (1.0 - ema_beta) * new,
384                state.ema_params,
385                params,
386            )
387 
388        watch_stats = None
389        if watch_config is not None and compute_watch:
390            watch_stats = compute_watch_stats(
391                watch_targets=watch_targets,
392                include_norms=watch_config.include_norms,
393                include_per_parameter_norms=watch_config.include_per_parameter_norms,
394                include_histogram=watch_config.include_histograms,
395                split_scan_layers=watch_config.split_scan_layers,
396                params=state.params,
397                grads=grads,
398                updates=updates,
399                opt_state=state.opt_state,
400                model_tree_type=type(state.params),
401            )
402 
403        next_state = dataclasses.replace(
404            state,
405            step=state.step + one,
406            params=params,
407            opt_state=opt_state,
408            ema_params=ema_params,
409        )
410 
411        metrics = {"train/loss": loss}
412        if backward_flow_stats is not None:
413            metrics[_BACKWARD_FLOW_METRICS_KEY] = backward_flow_stats
414 
415        return next_state, metrics, watch_stats
416 
417    return train_step
