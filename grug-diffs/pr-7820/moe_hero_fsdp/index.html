37## What's distinctive about this run
38 
39### Architecture
40- **d6144, 48 layers, all MoE** (no dense layers). 48 heads, GQA with **12 local / 6 global KV
41  heads**, head_dim 128.
42- **128 experts, top-4** routing with **QB (query-bias) routing** (structural).
43- **2 shared experts**, each `shared_expert_intermediate_dim=3072` → 6144 total shared width
44  (the field is *per shared expert*).
45- **GatedNorm**, **XSA** (Exclusive Self-Attention: subtract the per-head component of the output
46  parallel to `v`), and a **headwise sigmoid attention gate** — all structural / always-on, no flags.
47- **SConv** — Inkling-style depthwise causal 1-D conv at all four sites (`k`, `v`, `attn`, `mlp`),
48  identity-init so it's inert at step 0.
49- **Sliding-window attention (512)** with **every 6th layer global** (full-causal). Short layers use
50  half-RoPE; global layers run **rope-free**. RoPE is the fused single-pass form (`rope_fused`).
51- **Always array-stacked**: all blocks run through one compiled `lax.scan` body (the unrolled
52  program OOMs). The per-layer sliding window rides in as precomputed FA4 bound arrays selected in
53  the scan.
54 
55### Systems (FSDP)
56- **Pure FSDP**: `expert_axis_size=1`, `replica_axis_size=1` → all 64 GPUs on the `data` axis.
57- **`expert_chunks=4`** — gather one quarter of the expert bank at a time (the largest MFU lever).
58- **`sonic_cute`** MoE backend (QuACK SM100 grouped-GEMM) and **`gpu_fa4_cute`** attention
59  (FA4 / CUTLASS 4.6).
60- **Large-vocab cross-entropy**: the plain-XLA path with `BlockSizes(v_block_size=4096)` (v=4096 is
61  the dominant lever for the 128k vocab; the SMEM-tiled `batched_xla` kernel caps the h*v weight
62  tile at ~99KB and cannot take v=4096). No liger, no pure-JAX chunked CE.
63- `offload_opt_state` to pinned host; `remat_mode="recompute_all"`.
64- Runtime env baked in: `JAX_ENABLE_PGLE=1`, `XLA_PYTHON_CLIENT_ALLOCATOR=cuda_async`.
65 
66### Optimizer — MuonH
67- **Muon direction** (Newton-Schulz orthogonalization) + a **Frobenius hyperball** scale-invariant
68  step. 4D expert stacks are orthogonalized by a **distributed** Newton-Schulz (`grugmuon_hero`):
69  always-NS, always-pad the 3D non-expert stacks, **intra-rack always-on** (never distributes over
70  the cross-rack DCN axis), and **SYRK** (QuACK symmetric GEMM for `X @ Xᵀ`) as a config, defaulting
71  on (`use_syrk=True`).
72- Three LR groups: **muonh** (matrices + GatedNorms), **adamh** (`lm_head` / `output_proj`),
73  **adam** (embeddings, router, attention gate, 1-D norm gains, the tiny SConv kernels).
74- LR / beta / epsilon come from the **May Recipe compute-scaling heuristic** (issue #5951) at
75  batch 1152 / 25 steps / d6144: `lr=0.05`, `adam_lr≈0.02512`, `beta1=0.9062`, `beta2≈0.96462`,
76  `epsilon≈4.84e-17`, linear schedule, **no gradient clipping**, no weight decay applied.
77- CE logsumexp **z-loss = 1e-4**. Router z-loss is **logged only**, not added to the loss.
78
