# CD14 monocyte gene-span/expression task: predeclared source gate

Target only BixBench-Verified `bix-22-q4`: join gene length and biotype by stable identifier, select protein-coding genes and the CD14 expression population, average biological samples, and report the Pearson association. The Verified inventory also requires a total-count filter. This is a new, narrower design on independent observed Parse PBMC data. The previously frozen four-group Parse gate failed because CD8 had 3–9 cells per donor; that result remains a failure and `bix-22-q1` remains uncovered. No gene-length correlation has been inspected for this source.

The observed input is [Parse Biosciences Evercode WT Mini v3 human PBMC](https://www.parsebiosciences.com/datasets/performance-of-evercode-wt-mini-v3-in-human-pbmcs/), explicitly CC BY 4.0 for the dataset, from four healthy donors. Use unchanged MatrixMarket counts, gene IDs and cell metadata at the URLs and SHA256 hashes recorded in [the source assessment](gene_length_expression_source_assessment.md). Use Ensembl GRCh38 release 111 GTF at that assessment's pinned URL and hash; Ensembl permits unrestricted use with attribution. The original BixBench sorted-cell data, capsules, reference notebooks and answers are excluded. Marker-defined CD14-like cells in single-cell UMI data are an adaptation to sorted-cell bulk data, not a reproduction of the original measurements.

Freeze these rules before the CD14-only gate computes any association:

1. MatrixMarket row *i* is metadata row *i*. Require exactly 4,861 unique barcodes, four named donors, positive row totals, and at least 99% agreement with metadata `tscp_count`. Legal explicit-zero coordinates contribute zero counts. Use all author-filtered cells; do not select donors or cells by the resulting correlation.
2. Reuse the marker panels, `log1p(10000 × marker count / cell total)` scoring, score/margin cutoffs, anchors, ambiguous policy and held-out markers frozen in the earlier four-group source assessment. Label cells CD4, CD8, B, monocyte, NK/other or ambiguous, but select **only monocyte** cells for the association. Require at least 25 monocyte cells in each of four donors and at most 65% unassigned/ambiguous overall. Require held-out `CD14` CPM enrichment of at least 1.5-fold over each other classified group in at least three donors. Report every cell's assignment and reason, per-donor group sizes and held-out QC. These are marker-defined cells, not author-provided FACS labels.
3. Match Parse stable Ensembl IDs to release-111 GTF gene features after stripping only version suffixes. Keep canonical chromosomes 1–22, X, Y and `gene_biotype=protein_coding`; gene span is inclusive `end − start + 1` base pairs. Require at least 15,000 unique protein-coding joins. Do not substitute transcript, union-exon or expression-derived effective length.
4. Sum raw UMI counts for each donor's selected monocyte cells across **all** Parse genes. Keep all four donor pseudobulks as distinct biological samples. Divide each gene count by its own donor's all-gene total and multiply by one million for CPM. An eligible gene must have **total observed monocyte count ≥10 across the four donors** and a matching canonical protein-coding span. Require at least 5,000 eligible genes and nonconstant vectors for the Pearson test. Report how many genes have CPM ≥1 in at least two donors as a separate prevalence QC measure; do **not** apply it as another eligibility filter. Include total count, per-donor counts and CPM, span and eligibility decision for every joined coding gene in the output.
5. For each eligible gene, take the arithmetic mean of the four donor CPM values with equal donor weight. Compute Pearson `r` and a two-sided p-value between **untransformed gene span in base pairs** and these untransformed mean CPM values over precisely the same eligible genes. Report donor count, gene count, `r` and p-value, with the complete gene-level table. CPM normalization is a declared modality adaptation to four single-cell donor pseudobulks; the primary coefficient has no log transforms and no extra prevalence filter. Do not tune thresholds after seeing the result.

The source gate must stop before endpoint computation if any identity, labeling, donor-count, held-out or annotation-overlap rule fails. Once those pass, inspect the frozen count/prevalence/eligibility gate and compute the association once. A passing source gate only permits task construction; endpoint credit requires a native-package oracle, complete artifact grading, scientific corruptions, empty output and a successful Harbor package run. The task must remain offline to a solver and grade cell-assignment/QC, pseudobulk counts and CPM, joined gene spans, total-count/prevalence decisions, gene means and the final association.
