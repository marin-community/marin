This cumulative recipe stage uses Qwen3-0.6B, the reasoning curriculum `curriculum-rl-pool@2026.08.29.1`, eight prompts with four completions per update, replacing the preceding stage’s 64 prompts with eight completions. It keeps native AdamW and native rewards/GRPO. The total prompt-plus-response window is 512 tokens. Sampler weight noise is drawn once as `delta_j = 0.05 * initial_weight_j * z_j`, with independent standard Gaussian `z_j`, and the same delta is added after each sampler refresh. Clean evaluation uses unperturbed weights. Here, score means the gradient of log token probability. SC subtracts the sampling-policy expectation of the advantage- and importance-weighted score, including the PPO clip mask. It approximates this expectation using the 128 highest-probability tokens under the sampling policy plus a modeled tail; the [frozen implementation](https://github.com/marin-community/MarinSkyRL/blob/0212d03c68bf1cf366776dfe08f99c6a33d43779/skyrl-train/skyrl_train/objective/score_centering.py) defines the exact correction.
