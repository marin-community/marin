# Midpoint Uncheatable metric audit

The ten midpoint runs log evaluator schema 2. It computes each component BPB as total scored loss bits divided by total scored bytes. The legacy evaluator instead averaged batch BPBs with scored-token weights, and its parent Uncheatable score weighted the seven components by their scored-token counts. Schema 2 also changes that parent to pooled-byte weighting. The frozen predictors were trained against the legacy component convention and token-weighted objective.

The plotted midpoint score uses the seven **observed schema-2 component BPBs with the frozen task weights** in `fit_uncheatable.json`. It does not use the new raw `eval/uncheatable_eval/bpb` parent score. The raw parent would shift these ten measurements by about 0.008--0.011 BPB solely through objective weighting. No predictor is refitted, no result-dependent offset is applied, and no measurement is synthesized.

A small component-estimator difference remains. In general, the legacy batch-weighted BPB cannot be recovered exactly from saved total token loss and pooled BPB: the per-batch loss/byte covariance is missing. The saved files contain aggregate component losses, not batch-loss sufficient statistics.

We quantify that difference from all 24 plotted legacy endpoints and their 98 saved evaluation checkpoints. For each component, schema-2 BPB divided by token loss supplies the fixed scored-token to scored-byte conversion for the validation population. Multiplying each historical token loss by this ratio reconstructs its pooled-byte component score up to floating-point accumulation. Applying the frozen task weights then gives pooled-minus-legacy aggregate differences from -0.000053785 to -0.000038881 BPB. For the 24 final endpoints alone the range is -0.000045986 to -0.000038915 BPB. The frozen weights reproduce the legacy parent directly from its old component BPBs within 0.000000153 BPB.

These ranges are an empirical audit of the saved models, not an exact bound on unseen outputs. The closest MARINER-versus-baseline absolute-error comparison at the Uncheatable midpoints is the spline path: MARINER is closer by 0.000631703 BPB. Even perturbing the midpoint by the maximum observed legacy estimator drift changes that comparison by at most twice 0.000053785 BPB, leaving every Uncheatable midpoint comparison unchanged. Each midpoint remains a single trainer seed.

`legacy_endpoint_metric_histories.json` preserves the 24 source URIs, per-source SHA-256 hashes and 98 metric rows. `metric_bridge_audit.json` contains every comparison, the seven fixed task weights, the pooled conversion factors and the raw midpoint-source path. `uncheatable_prediction_errors.json` scores the observed frozen-weight midpoints against the runtime-rounded frozen predictions.
