# Mechanistic surrogate discovery II

This directory contains the rerunnable local modeling and falsification work for
the 2026-07-19 surrogate-discovery drive. It extends the prior 41-route search
with the matched Delphi 3e18 one-phase panel and the now-exposed adversarial
development panel.

The running frontier phase-fiber panel is reserved for future confirmation and
is not read by any script in this directory.

Run scripts from the repository root:

```bash
export PYTHONPATH=.
uv run experiments/domain_phase_mix/exploratory/two_phase_many/mechanistic_surrogate_discovery_20260719/freeze_pareto_gate.py
```

The terminal result is deliberately negative: no tested route passed the frozen
gate. The final report retains a Pareto baseline for descriptive use and keeps
the future confirmation design inactive until a genuinely new model passes all
development audits. `final_synthesis/data_dictionary.md` fixes metric signs,
policy/refit semantics, support conventions, and intentional missing-value
patterns for the generated tables.

Generated artifacts are written under
`reference_outputs/mechanistic_surrogate_discovery_20260719/`. The frozen gate
is content-addressed and must not change after candidate generation begins.
