# Prompt Design Note

This task prompt adapts the search-control structure of OpenAI's public prompt for the Cycle Double Cover effort: an exact success condition, a genuinely diverse initial portfolio, dynamic rather than fixed allocation of parallel work, an explicit approach registry, early independence between routes, blocking rules for theorem-strength or non-identifiable gaps, concrete artifacts instead of vague status reports, repeated synthesis, and independent adversarial audit.

The scientific task differs in one important way. The source prompt assumes an affirmative proof exists and permits return only after success. Here a negative result is scientifically valid, and claiming a winner without support is harmful. The adapted prompt therefore preserves sustained search and adversarial review while explicitly allowing a rigorous no-go conclusion, freezing exposed-development data use, and requiring future untouched confirmation.
