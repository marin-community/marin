## Scope

The proposed minimum assumes a qualifying free and open-source, non-systemic GPAI release. Under that route, Article 53(1)(c)'s copyright policy and 53(1)(d)'s public training-content summary remain applicable. The selected technical-documentation and EU-representative exemptions need to match the actual release conditions. Code of Practice membership is voluntary. See [Article 53](https://ai-act-service-desk.ec.europa.eu/en/ai-act/article-53), [Article 54](https://ai-act-service-desk.ec.europa.eu/en/ai-act/article-54) and the [Commission's Code guidance](https://digital-strategy.ec.europa.eu/en/policies/contents-code-gpai).

As reported by the provider, weights are gated and no access requests have been approved. The repository is public. Neither staging uploads nor this package establishes external distribution or Union-market placement. The planned release is 5 November 2026; actual availability and placement timing remain to be recorded.

The five existing drafts are included. In packaged copies, checkout-only evidence links point to EVIDENCE.md or public sources, and the model-card license link points to the official license. Source drafts and frozen live upload cards are unchanged. Raw run telemetry, private incident records, credentials, storage paths and model weights are omitted. This zip is a review handoff; its internal review files are not intended for public model documentation.
