## Source-backed findings and relationships

- Intersect supports overlap extraction, full-record reporting, counts, overlap fractions, strandedness, split alignments and multiple B files. It is a shared component of coverage and chained filters.
- Coverage reports feature count and target breadth/depth per A interval; advanced usage composes BAM conversion and optional proper-pair filtering.
- Genomecov reports genome-wide depth distributions and bedgraph segments. Tutorial composition can isolate uncovered target bases.
- Jaccard reduces interval-set comparison to base-pair overlap similarity; the tutorial's DNase example is a distinct tissue-comparison application. The tutorial itself cautions that PCA is a toy example and considers heatmaps more informative for the distance matrix.
- Fisher tests overlap enrichment using a heuristic estimate of possible intervals. Its own documentation reports p-value inflation in comparison with shuffling and recommends simulation validation; keep statistical estimates and simulation validation distinct.
- Reldist measures a distribution over relative distances and demonstrates contrasting RefSeq exon relationships to AluY and GERP intervals. Three separate annotation/reference dataset records link those inputs because shared use does not establish shared provenance.
- Closest supports nearest-feature annotation and a GWAS-SNP-to-exon-distance question, but the puzzle provides no named dataset locations.
- Capture masking is a three-stage composition: slop target probes by 500 bp, complement against chromosome sizes, then mask a matching hg18 FASTA using the complement. Source files are placeholders, not identified assets.

## Gaps, deduplication, and continuation

Related tools remain separate where outputs answer different scientific questions: per-target coverage (`coverage`) versus genome-wide depth (`genomecov`); overlap membership (`intersect`) versus one-number similarity (`jaccard`), enrichment inference (`fisher`) and spatial-distance distribution (`reldist`); nearest feature (`closest`) versus overlap calls. The advanced capture-mask workflow is one composed unit because its stages jointly produce a masked reference.
