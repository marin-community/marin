prompt, repository identity/pin and generic source-access instructions.

finds the public command catalog or an equivalent source/build catalog. Check
entry-level accounting: inspected units, explicit aliases, specific exclusions,
and remaining leads. Simple scientific extraction/conversion/indexing operations
qualify. Check semantic accuracy and whether claimed exclusions are supported.

Also check JSONL fields/references, scientific input/output meanings, source pin
versus mutable binary/help revisions, coordinate/assembly prerequisites, data
identity, tool-role evidence and final source-map consistency. Counts are not
quality scores. No execution or task-authoring success is assessed. Requested
high effort and uncapped execution differ from earlier unspecified-effort,
partly capped UCSC runs, so this is not an isolated causal prompt comparison.
