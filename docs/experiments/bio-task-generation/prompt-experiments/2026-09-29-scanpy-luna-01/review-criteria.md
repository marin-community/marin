# Review criteria fixed before launch

Use the same general dimensions as the bedtools trials: source coverage,
meaningful unit boundaries, source evidence, data identity and input links, and
usefulness to the downstream author. Independently validate fields, unique IDs,
and references. Check source claims rather than rewarding a larger unit count.

For this test case, look for API operations and connected tutorial/notebook
analyses; a source map should expose inspected and uninspected collections.
Check whether units preserve input processing stages and state changed inside
AnnData objects, rather than only naming files. Check dataset identities and
relationships between processed representations. Check whether ordinary analysis
scripts and package use are incorrectly classified as creating bioinformatics
tools. These are reviewer probes, not a fixed inventory quota or worker hints.

This is a transfer probe with the exact prompt used in bedtools trial 03. It is
not a same-repository before/after comparison and cannot establish robustness
from one sample. No scientific acceptance threshold or aggregate score is set.
