## Scientific uses and inventory links

The tutorial provides a coherent regulatory genomics exercise: combine GWAS SNP intervals with human exons, CpG islands, enhancers/promoters, DNase hypersensitivity peaks, and hESC ChromHMM states. It motivates overlap classification, coverage fractions, Jaccard similarity, and randomized-placement comparison. That integrated operation is `bedtools2-tutorial-interval-overlap-annotation`. It is linked to distinct records for each named annotation or study-derived track because shared use does not make them one dataset.

Coverage analysis is a separate useful operation: compute per-interval depth and breadth from alignments or feature intervals. Official manual examples include exon coverage, properly paired alignments, and strand-specific read coverage. `bedtools2-tutorial-coverage-profiling` captures these supported workflows. `bedtools2-tutorial-complement-and-genomecov` records the distinct genome-boundary operation of deriving uncovered regions and summarizing depth over a genome. `bedtools2-docs-closest-gwas` records the variant-to-nearest-exon analysis explicitly posed by the tutorial.

The tutorial spans many additional commands and activities. These units are selected to cover distinct scientific operations rather than every flag or repeated command. The source boundary remains provisional; authoring should define assembly, supplied starting files, exact output, tie/overlap behavior, and grader contract.
