# Bind work to artifacts

Build handles in an `experiments/**` function. Bind a concrete work function from `lib/**` with `apply(...)` for keyword inputs, or construct `ArtifactStep(...)` when the step needs a typed config or custom `build_config`. `remote(fn, resources=...)` chooses execution resources. Use existing builders when required by current APIs, while keeping new dataset selection and pipeline policy in `experiments/**`.

In `apply`, an `ArtifactStep` input becomes a dependency and resolves to its path; `OUT` resolves to the output path. For direct `ArtifactStep`, list every consumed handle in `deps` and resolve it through `ctx.artifact_path(dep)` or `ctx.resolved(dep)` inside `build_config`. `ctx.resolved` cannot read records during fingerprinting; use `ctx.is_fingerprint` to emit a stable identity summary when a downstream config needs a dependency's value. See `experiments/references/reference_scaling_suite.py` for that case.

Choose an explicit `name` and `version` for each produced artifact. Identity-bearing inputs belong in `build_config`; execution choices belong in `runtime_args` and `ctx.runtime_arg(...)`. Use `ArtifactStep.adopt(...)` in the experiment for pre-existing outputs. Follow `experiments/AGENTS.md` for region-aware paths, pins, and mirrors. A fixed `name@version` with changed config warns and serves cached output; bump the version to build changed content. Use `dev` only for disposable runs. See [lazy artifacts](../../../../docs/explanations/lazy-artifacts.md) for API details.

The API currently encourages binding in `experiments/**` through `apply` and direct `ArtifactStep`, but `marin.experiment.data`, `train`, and `evaluation` expose library functions that construct handles. Those helpers ease common tasks while obscuring the placement rule. Do not duplicate them or add new library step factories. A broader migration should split their reusable work from binding calls, update every caller, and preserve artifact identities deliberately; it is separate from an ordinary pipeline edit.
