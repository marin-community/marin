# Curate experiment records

Choose the requested operation and read only its procedure:

- [Curate reports](references/reports.md): harvest experiment issue reports,
  merge canonical entries, and organize `docs/reports/index.md`.
- [Archive experiments](references/archive.md): publish the requested snapshot
  tag and canonical issue breadcrumbs. Archival does not authorize deleting
  experiment files.

Keep existing conclusions and canonical links. `manage-pr` owns publication
of repository changes; scheduled issue-summary maintenance follows
`infra/loom/procedures/scrub-experiment-issue-tldrs.md` only when assigned.
