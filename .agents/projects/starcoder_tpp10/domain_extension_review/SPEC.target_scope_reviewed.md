# Wikipedia and FineMath-3+ repetition sweeps at TPP10

Draft for scientific review, 11 September 2026. This extends the measured StarCoder experiment with two focus domains. No new training or data preparation is released by this document. The domain-specific builders and submission manifest still need implementation and validation.

## Question and scope

Measure whether different focus domains prefer different repetition levels when optimizing the same held-out loss, with model size, total token budget, tokenizer, finite focus-pool size, background mixture, and training recipe held fixed. Each run mixes one focus domain with the same six-component web background. There are three separate two-domain sweeps, not one mixture containing Wikipedia, FineMath, and StarCoder simultaneously.

The initial survey includes one target curve and one epoch-matched proxy curve for each new domain, with one trainer seed and one matched subset. It aims to locate the approximate minimum of each measured curve and compare the selected mixture fractions across scales. Reuse the measured StarCoder curves as the third domain. Do not add unmatched controls, replicate sweeps, extra matched subsets, or automatic refinement. "Target without simulated epoching" means using the finite parent directly; natural repetition is allowed.

The narrow result is a set of conditional mixture-response curves and observed grid minima. Changing p changes focus-domain exposure, repetition and replacement of web data together. Distinct observed minima therefore describe preferences along these fixed mixture paths; they do not identify intrinsic repetition tolerance. A sufficiently high common upper cap permits all these optima. A later comparison of cap-constrained proposals requires a separately specified proposer and selection protocol.

## Scope decision after review

The user explicitly excluded unmatched controls and multiple matched sweeps, then requested initial estimates of both target and matched-setting optima and inclusion of Uncheatable evaluation. The current plan therefore has one curve per scale per new domain, one seed, one subset, and no new StarCoder training. CC's earlier suggestion to add unmatched curves is not adopted. Keep P_j, S_j, N and D unchanged. The survey measures conditional mixture optima and proxy-to-target transfer; it does not by itself establish that a fixed upper cap is harmful.
