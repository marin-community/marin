## Hypothesis Queue

### Active

- `EP64-MFU-004`: Enable the exact Sonic clone-weight reduction adjoint. The
  real-shape microbenchmark is 3.24-4.63x faster with zero error; the rack A/B
  was stopped before producing a result.
- `EP64-MFU-005`: Reduce fixed BF16 token bytes or fuse peer arrival with expert
  consumption. v156 measures 10.29% communication-only time and a 25.7%
  perfect-hiding ceiling.
- `EP64-MFU-006`: Retry fused QKV only after a memory-reducing change. The local
  kernel path is faster, but the rack executable requested an 81.14-GiB arena.

### Falsified / Dead End

- NCCL 40, 48, and 64 CTA overrides exhaust HBM during the first token A2A.
- Serial 64-round `ppermute` exhausts HBM and does not provide pipelined expert
  work.
- The first MNNVL implementation regresses because it waits for every peer and
  copies the persistent fabric buffer into an XLA-owned output.
- Compact receiver-pooled ragged transport is exact but 1.07pp slower than the
  fixed receiver-ECHO path.
- Padding 1 gains only 0.049pp and exceeds 3% aggregate drop.
- Manual PGLE, scan unroll 2, and dispatch host offload regress.
- BF16 pipeline depth 4, sequential QKV pipelining, and fused QKV exhaust the
  training executable's memory arena after step 2.
- FP8 and wider shared experts are outside the requested configuration.
