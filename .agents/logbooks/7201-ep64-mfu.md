- Goal: exceed 30% steady MFU on 64 GB200 GPUs.
- Primary metrics: tail MFU, tokens/s, exact aggregate post-ECHO assignment drop,
  and loss.
- Constraints: shared-expert intermediate width 5,120; QB enabled; exact drop at
  most 3%; receiver-ECHO preserves the selected expert.

## Hypothesis Queue

### Active

- `EP64-MFU-001`: Reduce or overlap the receiver-ECHO token transport selected
  by the shared-5,120 profile. Next test: attribute the step-150 XPlane before
  changing the transport.
- `EP64-MFU-002`: Receiver-pooled ragged transport may avoid fixed-envelope
  bytes without returning to per-expert tiny messages. Next test: implement only
  if the baseline profile still attributes the largest removable block to the
  fixed token A2A.
- `EP64-MFU-003`: A persistent MNNVL transport fused with expert compute can
  remove the barrier and fabric-to-XLA copy that regressed the first peer-write
  prototype. Next test: design after the baseline profile quantifies the
  remaining gap to 30%.

### Falsified / Dead End

- NCCL 40, 48, and 64 CTA overrides exhaust HBM during the first token A2A.
- Serial 64-round `ppermute` exhausts HBM and does not provide pipelined expert
  work.
- The first MNNVL implementation regresses because it waits for every peer and
  copies the persistent fabric buffer into an XLA-owned output.
