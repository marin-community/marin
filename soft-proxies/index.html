The α→0 double-limit forecast

Forecasting the compute a model needs to solve a task — from models that can't.

Decode with α·logits(Llama-70B) + (1−α)·logits(Delphi): a strong fixed scaffold that a weak model only steers. Turning the scaffold down forces the small model to carry more, and the double limit reads a scaling law off how much scaffold each model needs:

  1. Fit each model's α→pass@1 curve as an asymmetric sigmoid (Richards; lower asymptote plus shared pure-Llama ceiling). Pick a target X and estimate the first α it needs to reach X, using the measured α-grid where it crosses the target.
  2. Regress that α-required against log-FLOPs, using a local low-α fit when the observed suite gets close to the α→0 root.
  3. Extrapolate the line to α-required = 0: the FLOPs at which an unscaffolded model reaches X.
